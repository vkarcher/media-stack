# Agents

Pour installer cette stack : suivez [docs/agent-setup.md](docs/agent-setup.md), dans l'ordre, et arrêtez-vous aux points qui demandent l'humain.

Trois règles qui valent partout dans ce dépôt :

- ne démarrez aucun conteneur avant la phase 3 de ce document ;
- aucun secret dans un fichier versionné ni dans une commande ;
- une vérification qui échoue (hardlinks, fuite VPN) est une décision, pas un obstacle : arrêtez-vous et demandez.
